# 仕様書 — ギター指板トレーニング

このファイルが**唯一の正**です。実装を変更したら必ずここを更新し、
`tests/` のテストが仕様の各項目を検証している状態を保ちます。

各項目の `[S-xxx]` は仕様IDです。テストコードのタイトルにこのIDを含めてください。

---

## 1. アプリ全体

### 1.1 画面構成 [S-APP-01]

| 領域 | 内容 |
| --- | --- |
| モードタブ | 🎵 音名クイズ / 🎯 度数クイズ / 🎹 コードシェイプ |
| 設定パネル | 現在のモードに関係する設定のみ表示する |
| 問題表示 | 見出し（`#question-label`）・問題（`#question-note`）・補足（`#question-sub`） |
| 指板 | SVG。0（開放弦）〜24フレット、**1弦が上・6弦が下**、**0フレットが左** |
| フィードバック | 正解／不正解のメッセージ |
| 操作 | 「選択をクリア」（コードモードのみ）／「次の問題 →」／「スコアをリセット」 |
| スコア | 正解数・出題数・正答率・連続正解・最高連続 |

### 1.2 モード切替 [S-APP-02]

- モードは `note` / `degree` / `chord` の3種。
- `#app` に `is-note` / `is-degree` / `is-chord` のいずれか1つが付く。
- 設定パネルの `.mode-note` / `.mode-degree` / `.mode-chord` は、対応するモードのときだけ表示する。
- モードを切り替えてもスコアは**モードごとに独立**して保持される。

### 1.3 設定の永続化 [S-APP-03]

- 設定は localStorage キー `guitar-game-settings` に保存する。
- 読み込み時は既定値とマージするため、キーが増えても既存ユーザーの設定は壊れない。
- 保存値が現在の選択肢に存在しない場合（旧バージョンの値など）は既定値に戻して保存し直す。

### 1.4 共通設定 [S-APP-04]

| 設定 | 選択肢 | 既定 |
| --- | --- | --- |
| チューニング | スタンダード / ドロップD / 半音下げ | スタンダード |
| サウンド | ON / OFF | ON |
| 音色 | アコースティック / ガット / クリーン / クランチ / ディストーション / ブリッジミュート | アコースティック |
| 音量 | 0〜100% | 23% |
| 自動送り | ON / OFF | **ON** |
| 練習モード（全ポジション表示） | ON / OFF | OFF |

### 1.5 自動送り [S-APP-05]

- **既定は ON。**
- ON のとき、**正解した場合のみ**一定時間後に自動で次の問題へ進む。
  - 音名クイズ・度数クイズ: 900ms
  - コードシェイプクイズ: 1300ms（アルペジオ再生を聴ける時間を確保）
- **不正解のときは自動で進まない**（正解を確認させるため）。
- OFF のとき、および不正解のときは「次の問題 →」ボタンにフォーカスが移る。
- モード切替・設定変更時は予約済みの自動送りタイマーを破棄する。

### 1.6 サウンド [S-APP-06]

- 指板をクリックすると、その位置の実音高が鳴る（回答済みでも鳴る）。
- 音名／度数クイズで不正解のときは、550ms 後に正解位置の音を鳴らす。
- コードシェイプクイズで正解したときは、シェイプを低音弦からアルペジオ再生する。
  不正解のときは 500ms 後に正しいシェイプをアルペジオ再生する。
- 音色を変更したときは 3弦開放を試聴再生する。

### 1.7 キーボード [S-APP-07]

- `Enter` または `Space` で「次の問題 →」（ボタンが有効なときのみ）。

## 2. 音名クイズ [S-NOTE]

### 2.1 出題 [S-NOTE-01]

- ランダムな音名を1つ出題し、その音がある指板上の位置をクリックして答える。
- 同じ音名が2問続けて出題されない。

### 2.2 設定 [S-NOTE-02]

| 設定 | 選択肢 | 既定 |
| --- | --- | --- |
| 音名表記 | `C D E F G A B` / `ド レ ミ ファ ソ ラ シ` | 英語 |
| 出題範囲 | ナチュラル音のみ（7音） / 全12音 | ナチュラル |
| ♯/♭の表記 | シャープ / フラット / 両方 | シャープ |

### 2.3 判定 [S-NOTE-03]

- クリックした位置のピッチクラスが出題と一致すれば正解（オクターブ違いは問わない）。
- 正解: 押した位置に緑のマーカー、「正解！ 🎉」。
- 不正解: 押した位置に赤のマーカー、正解位置すべてに緑のマーカー、
  「残念… そこは 〇 です。〇 は緑の位置。」。

## 3. 度数クイズ [S-DEG]

### 3.1 出題 [S-DEG-01]

- 指板上にルートを青い **R** で表示し、そこから見た度数（例: `III`、`m3`）を出題する。
- ユーザーは該当する度数の位置をクリックして答える。
- 同じ度数が2問続けて出題されない。

### 3.2 設定 [S-DEG-02]

| 設定 | 選択肢 | 既定 |
| --- | --- | --- |
| 度数の表記 | ローマ数字（♭III） / 音程名（m3） | ローマ数字 |
| 出題する度数 | コードトーン / メジャースケール / ナチュラル・ハーモニック・メロディックマイナー / メジャー・マイナーペンタトニック / ブルース / 全12音程 | コードトーン |
| ルートの決め方 | 毎問ランダム / ルート音を固定 / ルート位置を固定 | ランダム |
| ルートの弦 | 1〜6弦から複数選択（最低1本） | 6弦・5弦 |
| 回答できる範囲 | ルート周辺（±4フレット） / 指板全体 | ルート周辺 |

- ルートは 0〜12フレットに配置する。

### 3.3 判定 [S-DEG-03]

- 押した位置のルートからの度数が出題と一致し、かつ回答範囲内なら正解。
- 度数は合っているが回答範囲外のときは、通常の不正解とは区別したメッセージを出す。
- 不正解時は正解位置に緑のマーカーと度数ラベルを表示する。

## 4. コードシェイプクイズ [S-CHORD]

### 4.1 出題 [S-CHORD-01]

- コードネーム（例: `Cmaj7`）を出題し、指板を**複数クリック**して押さえる。
- 同じ「コード種類 × ルート位置」が2問続けて出題されない。

### 4.2 ボイシング [S-CHORD-02]

| ID | 表示 | 構成音 | 使う弦（ルート弦を S とする） |
| --- | --- | --- | --- |
| `triad` | トライアド（R・3rd・5th） | R, 3rd, 5th | S, S-1, S-2 |
| `seventh` | セブンス（R・3rd・5th・7th） | R, 3rd, 5th, 7th | S, S-1, S-2, S-3 |
| `guide` | ガイドトーン（R・3rd・7th／5th省略） | R, 7th, 3rd（低音側から） | S, S-2, S-3 |

### 4.3 コードの種類 [S-CHORD-03]

- トライアド系: メジャー / マイナー / ディミニッシュ / オーギュメント / サスフォー
- セブンス系: maj7 / 7th / m7 / m7♭5 / dim7 / mMaj7
- `triad` ボイシングではトライアド系のみ、`seventh` と `guide` ではセブンス系のみを選べる。
- 複数選択でき、**最低1つは選択されている**状態を保つ。

### 4.4 ルート弦 [S-CHORD-04]

- 6弦 / 5弦 / 4弦 / 3弦から複数選択（既定は6弦・5弦、最低1本）。
- **4音を使う `seventh` と、S-3 弦を使う `guide` では 3弦ルートは選べない**（弦が足りないため）。
  ボイシングを切り替えたとき、選べなくなった弦は自動的に選択から外す。

### 4.5 シェイプ生成 [S-CHORD-05]

- ルート位置は 0〜12フレットからランダムに選ぶ。
- 各弦に1音ずつ、低音弦から高音弦へ**音高が昇順**になるよう、
  条件を満たす最も低いフレットを選ぶ（クローズボイシング）。
- 次の制約をすべて満たすシェイプだけを出題する。満たせない場合は別のルート位置を選び直す。
  - 押弦するフレット（0を除く）の幅が **5フレット以内**
  - 隣り合う構成音の音程が **12半音以内**（開放弦ルートから遠く離れた音を選ばない）

### 4.6 回答 [S-CHORD-06]

- 「ルートを表示する」ON（既定）のとき、ルート位置に青い **R** を表示し、
  ユーザーは**残りの構成音だけ**をクリックする。
- OFF のときはルートも含めて全構成音をクリックする。
- クリックした位置はオレンジの「選択中」マーカーになる。
  もう一度クリックすると選択を解除できる。
- 必要な音数に達した時点で**自動的に判定**する。
- 「選択をクリア」ボタンで、判定前の選択をすべて解除できる。
- 補足行には常に「ボイシング名 ／ ルート位置（表示ONまたは回答後のみ） ／ あと N 音（n/N 選択中）」を表示する。

### 4.7 判定 [S-CHORD-07]

- 選んだ位置の集合が正解シェイプと**完全一致**したときのみ正解。
- 正解: 選んだ位置を緑のマーカーにし、各音に度数ラベル（`R` `3` `5` `M7` など）を表示。
- 不正解: 間違えた位置を赤、選ばれなかった正解位置を緑で表示する。

## 5. テスト方針

- `npm run check`（= `tsc --noEmit` + `vitest run`）が通ることをもって「仕様を満たしている」とする。
- テストは `tests/` に置き、`describe` / `it` のタイトルに仕様ID（例: `[S-CHORD-05]`）を含める。
  - `tests/core.test.ts` — 音名・度数・チューニング・コードシェイプ生成の純ロジック
  - `tests/quiz.test.ts` — `Quiz` / `DegreeQuiz` / `ChordQuiz` の出題・判定ロジック
  - `tests/app.test.ts` — jsdom 上で `src/main.ts` を実際に起動する結合テスト
    （画面構成・モード切替・設定の永続化・**自動送り**・キーボード操作）
  - `tests/setup.ts` — Node 26 では `globalThis.localStorage` が undefined になり jsdom のものを
    覆い隠すため、メモリ実装を差し込む
- ロジック（`src/core`, `src/ui/*Quiz.ts`）は単体テストで網羅する。
- 新しい仕様を追加したら、対応するテストも必ず追加する。テストの無い仕様は未実装とみなす。
- 既存のテストを「通らないから」という理由で削除・スキップしない。仕様変更なら本書とテストを両方直す。
- ブラウザでの手動確認を行う場合、**localStorage の設定を書き換えたら必ず元に戻す**こと
  （検証のつもりでユーザーの設定を変えてしまう事故を防ぐ）。
  手動確認より `tests/app.test.ts` への自動テスト追加を優先する。
