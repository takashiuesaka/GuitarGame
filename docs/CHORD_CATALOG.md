# 定番コードフォーム・カタログ

> このファイルは `npm run catalog` で自動生成される。手で編集しない。
> 元データは `src/core/chordCatalog.ts`、仕様は `docs/SPEC.md` の [S-CATALOG] を参照。

全 264 エントリ。

タブ譜は **6弦→1弦** の順に並べたフレット番号で、`x` はミュート（弾かない弦）。
ルート弦・転回形・構成音は、タブ譜から機械的に導出したもの。
