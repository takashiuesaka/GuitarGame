# 🎸 ギター指板トレーニング

エレキギターの指板の知識（音名・度数）を身につけるブラウザゲームです。
24フレットの指板をクリックして回答し、正解／不正解を即座にフィードバックします。

## セットアップ

```bash
npm install
npm run dev     # http://localhost:5173/ で起動
npm run build   # 型チェック + 本番ビルド (dist/)
npm run preview # ビルド結果の確認
```

## ゲームモード

### 🎵 音名クイズ

ランダムに表示される音名の位置を指板から探してクリックします。

- **音名表記**: `C D E F G A B` ／ `ド レ ミ ファ ソ ラ シ`
- **出題範囲**: ナチュラル音のみ（7音）／ ♯・♭を含む全12音
- **♯/♭の表記**: シャープ（C♯）／ フラット（D♭）／ 両方（C♯/D♭）

### 🎯 度数クイズ

指板上に表示されたルート（青い **R**）から見て、指定された度数の位置をクリックします。

- **度数の表記**: ローマ数字（♭III）／ 音程名（m3）
- **出題する度数**: コードトーン、メジャースケール、ナチュラル／ハーモニック／メロディックマイナー、
  メジャー・マイナーペンタトニック、ブルーススケール、全12音程
- **ルートの決め方**:
  - 毎問ランダム
  - ルート音を固定（位置は毎問変わる）— 同じキーで指板全体を把握する練習
  - ルート位置を固定 — 1つのフォームを体に叩き込む練習
- **ルートの弦**: 1〜6弦から複数選択
- **回答できる範囲**: ルート周辺（±4フレット）／ 指板全体

## 共通機能

- **指板**: 0（開放弦）〜24フレット、1弦が上・6弦が下
- **チューニング**: スタンダード／ドロップD／半音下げ
- **サウンド**: クリックした位置の音が実音高で鳴ります（Web Audio API / Karplus-Strong 合成、音源ファイル不要）
  - 音色プリセット: アコースティック、ガットギター、エレキ・クリーン／クランチ／ディストーション、ブリッジミュート
  - 不正解時は正解の音を自動で再生
- **練習モード**: 全ポジションに音名（または度数）を表示
- **自動送り**: 正解すると自動で次の問題へ
- **スコア**: 正解数／出題数／正答率／連続正解／最高連続（モードごとに独立）
- 設定は localStorage に保存されます

## 技術構成

- Vite + TypeScript（フレームワークなし）
- 指板は SVG で描画
- サウンドは Web Audio API による Karplus-Strong 撥弦合成

```
src/
├─ main.ts              画面組み立て・設定・モード切替
├─ style.css
├─ core/
│   ├─ notes.ts         音名とピッチクラス
│   ├─ degrees.ts       度数とスケール定義
│   ├─ tuning.ts        チューニング定義
│   ├─ fretboard.ts     弦×フレット → 音名/MIDI の変換
│   └─ audio.ts         撥弦音シンセと音色プリセット
└─ ui/
    ├─ Fretboard.ts     SVG指板の描画とクリック処理
    ├─ Quiz.ts          音名クイズのロジック
    └─ DegreeQuiz.ts    度数クイズのロジック
```
