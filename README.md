# 🎸 ギター指板トレーニング

エレキギターの指板の知識（音名・度数）を身につけるブラウザゲームです。
24フレットの指板をクリックして回答し、正解／不正解を即座にフィードバックします。

GitHub Pages で公開中です。ブラウザだけでそのまま試せます:
https://takashiuesaka.github.io/GuitarGame/

## セットアップ

```bash
npm install
npm run dev     # http://localhost:5173/ で起動
npm run build   # 型チェック + 本番ビルド (dist/)
npm run preview # ビルド結果の確認
npm test        # テスト実行 (vitest)
npm run check   # 型チェック + テスト（仕様適合の判定基準）
npm run catalog # docs/CHORD_CATALOG.md を再生成
npm run catalog:scales # docs/SCALE_CATALOG.md を再生成
```

## ゲームモード

### 🎵 音名クイズ

ランダムに表示される音名の位置を指板から探してクリックします。

- **音名表記**: `C D E F G A B` ／ `ド レ ミ ファ ソ ラ シ`
- **出題範囲**: ナチュラル音のみ（7音）／ ♯・♭を含む全12音
- **♯/♭の表記**: シャープ（C♯）／ フラット（D♭）／ 両方（C♯/D♭）
- **ブロック適用（ON/OFF）**: ONなら「ブロック内の同じ音名をすべて探す」、OFFなら従来の「指板全体（1か所で正解）」になります。
- **カスタムブロック**: 開始・終了の弦とフレットを指定してONにします（既定の範囲は**1〜3弦・0〜4フレット**、適用はOFF）。
  ON中に範囲を変える場合は「範囲を更新」を押してください。OFFにしても指定済み範囲は保持されます。
  ブロックには現在のチューニングで**1オクターブ分の全12音**が必要です。不足する範囲は理由を表示して適用しません。
- **スケール運指カタログ**: カスタム方式を残し、実際の教則に基づく**メジャー7形・ナチュラルマイナー4形**も選べます。
  スケール（各12キー）→ルート弦→ルートフレット→高音側／低音側／両側→運指パターンの順で選択します。
  例は **Cメジャー・6弦8f・高音側**。成立する候補だけが表示され、条件変更は即反映されます。
  外枠内の全部ではなく、**○とRで示した実際の運指位置だけ**が回答対象です。
  スケールの7構成音と最低1オクターブが必要で、出題範囲は「ナチュラル音／全12音」との共通部分になります。
  高低は実音高で区別し、原典の運指から音域を抽出します。
  標準調弦のCメジャー6弦8fでは、下のC2が指板にないため低音側だけの1オクターブは選べません。
  方式を戻せば以前のカスタム範囲を使えます。出典と収録座標は[カタログ](docs/SCALE_CATALOG.md)を参照してください。
- **ブロック内は全位置が必須**: オクターブ違いも、同じ高さの別ポジションもすべて探します。
  正しい位置は緑になり、発見数と残りを表示。最後の1か所を見つけて初めて正解・自動送りになります。
  違う音を選ぶと不正解になり、ブロック内の正解を表示します。範囲外のクリックや同じ位置の再クリックは採点に影響しません。
  練習モードの音名表示もブロック内だけに限定されます。

### 🎯 度数クイズ

指板上に表示されたルート（青い **R**）から見て、指定された度数の位置をクリックします。

- **度数の表記**: ローマ数字（♭III）／ 音程名（m3）
- **出題する度数**: コードトーン、メジャースケール、ナチュラル／ハーモニック／メロディックマイナー、
  メジャー・マイナーペンタトニック、ブルーススケール、全12音程
- **ルートの決め方**:
  - 毎問ランダム
  - ルート音を固定（位置は毎問変わる）— 同じキーで指板全体を把握する練習
  - ルート位置を固定 — 1つのフォームを体に叩き込む練習
- **ルートの弦**: 1〜6弦から複数選択
- **回答できる範囲**: ルート周辺（±4フレット）／ 指板全体

### 🎹 コードシェイプクイズ

出題されたコード（例: `Cmaj7`）を、指板を複数クリックして押さえます。必要な音数を選び終えると自動で判定します。

正解になるのは、教則本やレッスンサイトで実際に教えられている
**[定番コードフォームのカタログ](docs/CHORD_CATALOG.md)** に載っている押さえ方だけです。
理屈の上で成立するだけの、実際には使われない形は正解になりません。

- **ボイシング**:
  - トライアド（R・3rd・5th）— オクターブ重複のない3音
  - セブンス（R・3rd・5th・7th）— オクターブ重複のない4音
  - ガイドトーン（R・3rd・7th／5th省略）— ジャズの定番シェルボイシング
  - コードフォーム（開放・バレー）— 構成音をオクターブで重ねた4〜6音。
    E フォーム／A フォームのバレーコードや開放 C・G・D はここ
- **コードの種類**:
  - トライアド: メジャー、マイナー、ディミニッシュ、オーギュメント、サスフォー
  - セブンス: maj7、7th、m7、m7♭5、dim7、mMaj7
  - ガイドトーン: maj7、7th、m7、mMaj7（m7♭5・dim7 は♭5が要なので5度を省略できません）
  - コードフォーム: m7♭5 以外（定番の開放・バレーフォームがないため）
- **転回形**: 基本形／第1転回／第2転回／第3転回から複数選択（既定は**基本形のみ**）。
  トライアドは第2転回まで、セブンスは第3転回まで選べます。
  ガイドトーンとコードフォームは低音部にルートを置く形が定番なので基本形だけです。
  - **転回形を複数選んだときは、そのどれで答えても正解**です。どれを狙うか指定されないので、
    押さえられる形で答えてください。正解すると「第1転回でした」とどの形だったかが示され、
    まだ答えていない転回形も表示されます。
  - **選んだ転回形を連続で出題する**（既定でオン）: オンにすると、同じルート弦で転回形の数だけ続けて
    出題します。2問目以降は**まだ答えていない転回形**が正解になるので、
    答えやすい形から順に埋めていけます。出題エリアにオレンジ色のバッジで
    「押さえるのは 基本形・第2転回 のどれでもOK」「次に押さえるのは 第2転回」と表示され、
    すべて答えると緑色に変わります。
- **ルート弦**: 6弦／5弦／4弦／3弦／2弦／1弦から複数選択。
  カタログに定番フォームがある弦だけが並びます（ガイドトーンは6弦・5弦、
  コードフォームは6〜4弦、ドロップDでは6弦を使うフォームが成立しないので5弦以降）。
  **選んだ転回形によっても変わります**。基本形はどの弦セットでも最低音弦がルートなので、
  高音弦ルートは転回形を選んだときだけ現れます。
- **ルートを表示する**: オンならルート位置が青い **R** で示され、残りの構成音だけを答えます。
  オフにするとルートも自分で探します。
- **押さえ方は1通りではありません**: 同じ転回形でも複数のフォームがあり、**弦を飛ばした**
  押さえ方も正解になります。カタログにない押さえ方や、選んでいない転回形は不正解です。
  オクターブ重複を含む形は「コードフォーム」ボイシングでのみ正解になります。
- **判定のタイミング**: 選んだ位置が正解シェイプのどれかと一致した瞬間に自動で判定します。
  一致しないまま答えを確定したいときは「**回答する**」ボタンを押します。
- **連続出題**: ルート弦を複数選んでいると、1つのコードに対して選んだ弦の数だけ
  低音弦から順に出題されます。転回形の連続出題をオンにすると、同じ弦がさらに
  転回形の数だけ続きます。途中で間違えても、すべてのシェイプを答えます。
- 正解すると、そのシェイプをアルペジオで再生します。不正解なら最も近い正解シェイプを緑で表示します。

## 共通機能

- **指板**: 0（開放弦）〜24フレット、1弦が上・6弦が下
- **チューニング**: スタンダード／ドロップD／半音下げ
- **サウンド**: クリックした位置の音が実音高で鳴ります（Web Audio API / Karplus-Strong 合成、音源ファイル不要）
  - 音色プリセット: アコースティック、ガットギター、エレキ・クリーン／クランチ／ディストーション、ブリッジミュート
  - 不正解時は正解の音を自動で再生
- **練習モード**: 全ポジションに音名（または度数）を表示
- **自動送り**: 正解すると自動で次の問題へ
- **スコア**: 正解数／出題数／正答率／連続正解／最高連続（モードごとに独立）
- 設定は localStorage に保存されます

## 技術構成

- Vite + TypeScript（フレームワークなし）
- 指板は SVG で描画
- サウンドは Web Audio API による Karplus-Strong 撥弦合成

## テスト

仕様（`docs/SPEC.md`）の各項目には `[S-APP-05]` のような仕様IDが付いており、
テストの `describe` / `it` タイトルに同じIDを書いて対応づけています。

```bash
npm test          # 一度だけ実行
npm run test:watch
npm run check     # tsc --noEmit && vitest run
```


## デプロイ（GitHub Pages）

サーバー処理を持たない静的サイトなので、GitHub Pages だけで公開できます。
`main` ブランチへ push すると `.github/workflows/deploy-pages.yml` が動き、
型チェック → テスト → `vite build` → `dist/` を Pages へデプロイします。

初回だけリポジトリ側の設定が必要です。

1. GitHub の **Settings → Pages** を開く
2. **Build and deployment** の **Source** を **GitHub Actions** に変更する

公開 URL は `https://takashiuesaka.github.io/GuitarGame/` です。
`vite.config.ts` の `base` は `"./"`（相対パス）にしてあるため、
サブディレクトリ配信でもアセットの参照が壊れません。
